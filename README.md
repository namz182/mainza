# Portfolio Website

This is a personal portfolio website. It showcases projects, certifications, and contact information.

## Features
- Home, About, Projects, and Contact pages
- Project screenshots and certificate images
- Downloadable CV

## Styles

The interface uses Tailwind CSS 4 and daisyUI 5, with locally bundled Lucide icons. Install the development dependencies with `npm install`, then build the assets with `npm run build`. Use `npm run watch:css` while editing PHP templates and styles.
